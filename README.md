# Retail Analytics & Price Prediction Project
This project explores 3 retail datasets (products, customer feedback, and transactions) to extract actionable business insights and predict product pricing. It combines data manipulation, visualization, and regression modeling to support data-driven decisions in sales and customer experience.

**Tools & Libraries**:
pandas, numpy, matplotlib, seaborn, scikit-learn

**Key Highlights**:

- Merged datasets for holistic analysis of sales and customer sentiment

- Sales trends by category, product ratings, and issue identification

- Linear Regression to predict product prices

- Model evaluation using R² to assess accuracy

- Summary reporting for business insight delivery
